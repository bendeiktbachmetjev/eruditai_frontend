# EPUB Text Selection - How to Use

## Two Ways to Select Text in EPUB:

### Method 1: Normal Text Selection (Drag)
1. **Touch and drag** to select text normally
2. **Wait 200ms** after you finish selecting
3. Button "Generate Flashcard" will appear
4. **Tap the button** to create flashcard

### Method 2: Long Press Selection (Alternative)
1. **Long press** (hold for 0.5 seconds) on any text
2. Button "Generate Flashcard" will appear immediately
3. **Tap the button** to create flashcard

## Tips:
- **Minimum 3 characters** required for selection
- **Click empty space** to clear selection
- **Both methods work** - use whichever feels more comfortable
- **PDF works the same** as Method 1 (normal drag selection)

## Troubleshooting:
- If normal selection doesn't work → try long press
- If button doesn't appear → make sure text is longer than 3 characters
- If selection disappears → try selecting more slowly
