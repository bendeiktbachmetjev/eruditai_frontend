# 🔐 Ограничение API ключа Firebase (без регенерации)

Если в Firebase Console нет опции для регенерации ключа, можно **ограничить его использование** - это защитит ваши ресурсы.

## Пошаговая инструкция

### Шаг 1: Откройте Google Cloud Console

1. Перейдите на https://console.cloud.google.com/
2. Войдите в свой аккаунт Google
3. **Выберите проект**: `erudit-ai` (или найдите проект Firebase `erudit-ai`)

### Шаг 2: Найдите API ключ

1. В левом меню нажмите на **"APIs & Services"** (APIs и сервисы)
2. Выберите **"Credentials"** (Учетные данные)
3. В разделе **"API keys"** найдите ключ:
   - `AIzaSyBa29Zw2NEbIS4BZCrMXkL1RSywLcxkfE0`
   - Или любой другой Firebase API ключ для вашего проекта

### Шаг 3: Ограничьте использование ключа

Нажмите на ключ для редактирования и настройте ограничения:

#### 3.1. Ограничение по приложениям (Application restrictions)

1. Выберите **"iOS apps"** (iOS приложения)
2. Нажмите **"Add an item"** (Добавить элемент)
3. Введите:
   - **Bundle ID**: `com.benedikt.Erudit-AI`
   - **App Store ID**: (можно оставить пустым или указать, если приложение уже в App Store)
4. Нажмите **"Save"** (Сохранить)

#### 3.2. Ограничение по API (API restrictions)

1. Выберите **"Restrict key"** (Ограничить ключ)
2. Выберите только необходимые API:
   - ✅ **Firebase Installations API**
   - ✅ **Firebase Remote Config API**
   - ✅ **Firebase Realtime Database API** (если используете)
   - ✅ **Cloud Firestore API** (если используете)
   - ✅ **Firebase Authentication API** (если используете)
   - ✅ **Identity Toolkit API** (для Google Sign-In)
   - ✅ **Google Sign-In API** (если используете)
3. **Не включайте** ненужные API
4. Нажмите **"Save"** (Сохранить)

### Шаг 4: Проверьте ограничения

После сохранения:
1. Ключ будет работать **только** для вашего iOS приложения
2. Даже если кто-то получит ключ из git, он не сможет использовать его вне вашего приложения
3. Запросы с других приложений/платформ будут отклонены

## Альтернатива: Создать новое iOS приложение в Firebase

Если хотите полностью новые ключи:

1. Откройте **Firebase Console**: https://console.firebase.google.com/
2. Выберите проект **erudit-ai**
3. Перейдите: **⚙️ Settings** → **Project settings** → **General**
4. В разделе **"Your apps"** нажмите **"Add app"** → **iOS**
5. Введите Bundle ID: `com.benedikt.Erudit-AI-v2` (или другое имя)
6. Скачайте новый `GoogleService-Info.plist`
7. Обновите Bundle ID в Xcode на новый
8. Замените старый `GoogleService-Info.plist` новым

⚠️ **Внимание**: При этом нужно будет изменить Bundle ID в Xcode проекте.

## Что выбрать?

**Рекомендуется:** Ограничить существующий ключ (Шаги 1-3) - это быстрее и проще, и ключ останется работать для вашего приложения, но будет защищен от несанкционированного использования.

**Если очень важно:** Создать новое приложение (Шаг 4) - даст полностью новые ключи, но потребует изменения Bundle ID.

## Проверка безопасности после ограничения

После настройки ограничений:
1. Откройте приложение в Xcode
2. Соберите и запустите приложение
3. Убедитесь, что Firebase и авторизация работают
4. Попробуйте использовать ключ с другого приложения - должно быть отклонено
